## ✨ 2.x の主要機能（V2.0 で導入）

- 🛡️ **オンデマンドのダイアログガード**：`run_python_toolbox_tool` と `.pyt/.tbx/.atbx` GP 呼び出しは自動でガードを召喚し、終了時に自動で収隊します。操作と操作の間、システムにガードプロセスはありません。「第三方代码库执行（サードパーティコード実行）」の信頼ダイアログだけをクリックし、上書き/削除のダイアログは警告のみでクリックしません。
- 🧪 **テンプレート蒸留**：サンプル成図 → 版式 spec を 1 本のパイプライン（import → measure → patch → validate → preview → review → approve → apply）で。Pro 同梱の Python を使用し、別途インストールは不要。
- 🧰 **125 個の MCP ツール**：113 個の上流ツールに加えて `guard_summon / guard_status` と 10 個の `template_*` を追加。

本カスタマーエディションは動作に必要な**すべてのコンポーネント**を同梱しています。オフラインで動作し、**Python も pip もネットワークも不要**——ArcGIS Pro 本体以外に依存関係はありません。電池まで付いてきます 🔋

## 🎛️ 設定方法 — AI クライアントの接続

**前提**：ArcGIS Pro が開いていて、**MCP タブ**が **running** を表示していること。すべてのポートはローカルホストにのみバインドされます：

| ポート | 用途 |
|---|---|
| `6520` | MCP over HTTP —— すべての AI クライアントはここに接続 |
| `6510` | 旧版 TCP ブリッジ（現代のクライアントは使用しない） |
| `6511` | 任意の Pro 内 Python ブリッジ（`execute_arcpy_code`） |

### 🟣 Claude Code

```powershell
claude mcp add --transport http arcgis http://127.0.0.1:6520/mcp
claude mcp list
```

手動の等価構成（`~/.claude.json`）：

```json
{ "mcpServers": { "arcgis": { "type": "http", "url": "http://127.0.0.1:6520/mcp" } } }
```

削除は `claude mcp remove arcgis`、再追加は上記のコマンドで。

### 🖥️ Claude Desktop（同梱の stdio ブリッジを使用）

Claude Desktop は HTTP に直接接続できず、ローカルプロセスの起動のみに対応します——パッケージ同梱の純 PowerShell のブリッジ（Python 不要）を使ってください：

1. **Claude Desktop を完全に終了**します（トレイアイコンも含む）。
2. `install\02-configure-claude.cmd` を実行するか、設定を手動で編集します（先にバックアップしてください）。
3. 設定ファイルの場所は次のうち**最初に存在する**ディレクトリです：
   `%APPDATA%\Claude`、`%APPDATA%\Claude-3p`、`%LOCALAPPDATA%\Claude-3p`、`%LOCALAPPDATA%\Claude` —— ファイル名は `claude_desktop_config.json`。

```json
{
  "mcpServers": {
    "arcgis": {
      "command": "C:\\Windows\\System32\\WindowsPowerShell\\v1.0\\powershell.exe",
      "args": ["-NoProfile", "-ExecutionPolicy", "Bypass", "-File",
               "C:\\Users\\<your-username>\\AppData\\Local\\ArcGIS Pro MCP\\stdio-bridge.ps1"]
    }
  }
}
```

4. Claude Desktop を再度開き、ツール一覧に `arcgis` が表示されれば成功です。

### 🟢 Codex

`~/.codex/config.toml` に追加します（古い `arcgis` セクションがある場合は、古い `env` サブテーブルを含めてセクションごと置き換えます）：

```toml
[mcp_servers.arcgis]
url = "http://127.0.0.1:6520/mcp"
```

保存して Codex を再起動します。

### 🔧 その他の MCP クライアント

Streamable HTTP で `http://127.0.0.1:6520/mcp` に接続するか、上記の汎用 JSON を使用します。（Antigravity は `serverUrl` を使い、`type` は不要です。）

### ✅ 接続の確認

- `install\01-check.cmd` —— Pro のバージョン、add-in ハッシュ、ランタイム、ポート、クライアント設定をチェックします。
- `netstat -ano | findstr 6520` —— ポートが待ち受けていることを確認します。
- ログ：`%LOCALAPPDATA%\ArcGIS-MCP\addin.log`。

## 🎯 使用方法

**基本の流れ**：データのあるプロジェクトを開く → やりたいことを言う → アシスタントが自動でツールを選ぶ → 結果を確認する（画像はインラインで直接返ってきます）🎨

| こう言えます | 実際に起きること |
|---|---|
| 「面積で区県を階級色分けして、薄い赤から濃い緑で」 | `set_layer_renderer`（階級色分け） |
| 「人口 50 万超の県を選んで新しいフィーチャクラスとしてエクスポートして」 | `select_features` → `export_features` |
| 「道路を 500 メートルバッファして」 | `run_geoprocessing_tool`（Buffer） |
| 「各乡镇（郷鎮）ごとの耕地面積を統計して」 | `summarize_features` / `zonal_statistics` |
| 「現在の地図ビューをスクリーンショットして見せて」 | `export_map_view`（PNG を返す） |
| 「タイトル・凡例・縮尺バー・北矢印付きの A3 縦 PDF を出して」 | `create_layout` → `add_map_frame` → `add_layout_*` → `export_layout` |
| 「12 個のレイヤを同じシンボルで一括エクスポートして」 | `run_batch` または `execute_arcpy_code` |

**ツール名で呼び出す**：下の表のすべてのツールは、クライアントから名前で直接呼び出せます；`run_batch` は複数のコマンドを 1 往復で連鎖実行；専用ツールがない場合は `execute_arcpy_code` にフォールバックします。

**編集ルール**：編集は `save_edits` まで保留されます。保留中はデータがロックされ（削除/上書きは失敗）、`discard_edits` で保留中の編集を破棄できます。`delete_features` / `delete_dataset` は元に戻せません——実行前に影響範囲をアシスタントに説明させてください。

**バッチと高速化**：繰り返しが多くデータ量が大きい場合は、アシスタントに RunCode 用の冪等な arcpy スクリプトを書かせて一度に実行します；大きなプロジェクトは範囲/OID ごとに分割し、チェックポイントを残します。

## 🎨 出図・製図の使い方（プロンプトガイド）

このセクションは「AI への話しかけ方」を掘り下げます：ツール名を覚える必要はありません。下の 4 要素を伝えれば、アシスタントが自動で MCP ツール呼び出しに分解します。

### 4 つのことを言えば 1 回で正しく仕上がる

| 要素 | 伝えること | 例 |
|---|---|---|
| データ | レイヤ名、データパス、現在の選択セット | 「現在の地図の `区县边界` レイヤ」 |
| 操作 | 階級化フィールド/方法、バッファ距離、統計の定義 | 「`AREA` で 5 階級、自然分類」 |
| スタイル | 配色、フォントサイズ、凡例/縮尺バー/北矢印の位置、ベースマップ | 「薄い赤から濃い緑、凡例は右下」 |
| 出力 | 画像/PDF/新フィーチャクラス、解像度、保存先 | 「A3 横 PDF、300 dpi、`D:\out\` に保存」 |

**良いプロンプトと悪いプロンプト**
- ❌ 「地図をきれいにして」 —— 目標がなく、アシスタントは推測するしかありません。
- ✅ 「`土地利用` を `DLMC` で値別シンボル化し、配色はテンプレート `tpl-xxx` を参照、凡例は右下、そのあと A3 横 PDF を 300 dpi で `D:\out\landuse.pdf` にエクスポートして。」
- ❌ 「地図を出して」 —— 範囲・版式・出力が指定されていません。
- ✅ 「`研究区` レイヤを範囲に、縮尺 1:10000、A4 縦 PNG、タイトル『研究区土地利用現状』、凡例・縮尺バー・北矢印付きで。まずプレビュー画像を送って確認させて。」

### よくある失敗の一言リカバリ

- 「凡例が主図を覆っている」 → アシスタントが `legend` の座標か版式を調整します。
- 「ページ比率がおかしい/余白が多すぎる」 → map frame とページの比率を調整します。
- 「配色が派手すぎる/論文スタイルに合わない」 → 色ランプ、十六進数、またはテンプレート ID を指定します。
- 「まだエクスポートしないで、プレビューを見せて」 → アシスタントが先に `export_map_view` かレイアウトプレビューを実行します。

**効果**：「データ・操作・スタイル・出力」を一度に全部伝えれば、アシスタントは通常 1 往復で最終稿に近い図を作ります；以降の修正は差分を指すだけ（「凡例を右に 1 cm」）で、全部を言い直す必要はありません。

## 🛡️ ガードモジュールの使い方（オンデマンドのダイアログガード）

**解決する問題**：ArcGIS Pro がサードパーティ製 `.pyt` / Python ツール（RunCode.pyt など）を初めて実行するとき、「サードパーティ コード ライブラリ」の信頼ダイアログが表示され、無人運用ではタスクが止まってしまいます。ガードはダイアログが出る可能性のある操作の前にだけ喚起され、自動で「是(Y)」をクリックし、操作が終われば即座に終了します。

**2 つのトリガー方式**
1. **自動（2.x の既定）**：アシスタントが `run_python_toolbox_tool` / `execute_arcpy_code` を呼ぶ前に、add-in が自動でガードを arm し、操作終了時に settle して収隊します——通常はあなたが何かを言う必要はありません。
2. **手動召喚 `guard_summon`**：Pro 内で自分で `.pyt` を手動実行する場合、ENVI→Pro のインポート、その他アシスタント外の操作の場合。

**プロンプト例**

| こう言う | アシスタントがすること |
|---|---|
| 「次に Pro で手動で RunCode.pyt を実行する。先にガードを 10 分間召喚して；サードパーティコードの信頼ダイアログが出たら自動で『是』をクリックし、クリックできなければ最前面で音付きのリマインダーを出して」 | `guard_summon`（timeout_s≈600） |
| 「今回は警告のみ、自動クリックはしないで」 | `guard_summon`（alert_only） |
| 「さっきのガードが正常に終了したか見て」 | `guard_status` |
| 「RunCode を実行する前にガードを入れて」 | 自動 arm + settle |

**境界とパラメータ**
- 「第三方代码库执行（サードパーティコード実行）」の信頼ダイアログだけをクリック；上書き、削除など他の確認ダイアログには一切触れません。
- ボタンをクリックできないときは、最前面のリマインダー窓が最低 30 秒表示され、10 秒ごとに鳴ります。
- `timeout_s` はガードの生存時間を制御し、タイムアウトで自動終了します；`guard_status` でエンジンのパス・バージョンと直近 20 回のセッションを確認できます。
- 各 Pro プロセスは初回の信頼後に再表示されません；Pro を再起動すると再び必要になります。
- 1.1.4 には `guard_summon` がありません。パッケージ内の `install\03-dialog-guard.cmd`（既定 600 秒）で同じガードを起動します。

**効果**：無人運用の RunCode / ENVI 連携作図がダイアログで止まらなくなります；自動クリックが失敗しても、最前面表示＋アラート音のフォールバックがあり、静かにハングすることはありません。

## 🧪 蒸留モジュールの使い方（サンプル図 → 再利用可能な版式テンプレート）

「蒸留」はモデル学習**ではありません**。**サンプル成図**（論文図、教材図、優れた作図例）の中の版式知識——図框の位置、配色、フォントサイズ、凡例/縮尺バー/北矢印のレイアウト、失敗しやすいポイント——を、再利用可能な JSON テンプレート（spec）として抽出し、以後の出図にそのまま適用するものです。

**蒸留で得られるもの**：`template_id` ＋ spec 1 つ。内容は `canvas`（キャンバスサイズ/DPI）、`map_frame`、`title / legend / scale_bar / north_arrow`、`palette`、`typography`、`regions[]`、`pitfalls[]`、`measured`（測定証跡）、`review`（レビュー記録）。テンプレートライブラリの既定は `%LOCALAPPDATA%\ArcGIS Pro MCP\library`。

**効果**
- 版式の一貫性：同じ课题组（研究グループ）/同じプロジェクトの複数の図で、図框・フォントサイズ・凡例位置が統一されます。
- 繰り返しが減る：毎回「凡例は右下、タイトルは 22 号、配色は薄赤から濃緑」と口頭で言う必要がありません。
- 監査可能：各テンプレートには測定の出所、patch 内容、レビュアーと日付があり、担当が交代しても再現できます。
- 失敗防止：`pitfalls[]` が「凡例が図を覆う」といった問題を実行可能なチェックに変えます。

**完全なフローとプロンプト**

| ステップ | こう言えます | アシスタントの呼び出し | あなたが検収するもの |
|---|---|---|---|
| 1 投入 | 「`D:\samples\fig3.png` をテンプレートに蒸留して。名前『研究区概観図』、タグ：論文スタイル」 | `template_import` | 返ってきた `template_id` |
| 2 測定 | 「続けて測定して」 | `template_measure` | `h_lines/v_lines`、`palette_top`、DPI が妥当か |
| 3 セマンティクス | アシスタントが図を見て patch を書く（図框、凡例、フォントサイズ、分区、pitfalls） | `template_patch` | patch 内の座標/フォントサイズが期待どおりか |
| 4 検証 | 「検証して」 | `template_validate` | エラー 0；warning が許容できるか |
| 5 プレビュー | 「プレビュー画像を見せて」 | `template_preview` | ワイヤーフレームとサンプルの並列比較が一致するか |
| 6 レビュー/承認 | 「確認した。レビュアー柳皓文、備考：版式照合通過」 → 「承認して」 | `template_review` → `template_approve` | ステータスが `ready` になる |
| 7 適用 | 「テンプレート `tpl-xxx` で現在のプロジェクトを出図して」 | `template_apply` → 製図ツール | 成品図がテンプレート版式と一致するか |

**そのままコピーできるプロンプト**

1. **単図の完全蒸留**

```text
`D:\samples\fig3.png` を版式テンプレートに蒸留してください：
- 名前：研究区概観図；タグ：論文スタイル、A4 横
- 完全なフローで import → measure → patch → validate → preview を実行
- セマンティックフィールド（図框、凡例、縮尺バー、北矢印、フォントサイズ、配色、regions、pitfalls）はあなたが図を見て判断
- 各ステップの要点を報告；プレビュー画像をまず私に見せて確認、私が OK してから review + approve
- measured の数値を手で編集しないこと
```

2. **バッチ投入（まず測定のみ）**

```text
`D:\samples\` 配下のすべての PNG をスキャンし、1 枚ずつ import + measure して、名前はファイル名、
タグは一律 `候補テンプレート` を追加。セマンティック patch はまだ書かず、測定の集計表を
私に見せてください。私が選んだ後、1 枚ずつ精修します。
```

3. **テンプレートで出図**

```text
テンプレート `tpl-20261116-172854-57ec` で現在のプロジェクトを出図してください：
まず template_apply でテンプレートを読み、map_frame/palette/typography/pitfalls に従って
A4 横レイアウトを作成、タイトル「研究区土地利用現状」、300 dpi PDF を `D:\out\landuse.pdf` にエクスポート。
完了後、セルフチェック結果とプレビュー画像を私に送って検収させてください。
```

4. **ready 済みテンプレートの修正**

```text
`tpl-xxx` の凡例を右下（x=0.78, y=0.78, w=0.16, h=0.16）に移し、タイトルのフォントサイズを 22 に変更、
validate と preview を再実行して見せてください；measured には触れないこと。確認後に再度 review + approve。
```

5. **テンプレートの移行/共有**

```text
`tpl-xxx` を bundle.zip にエクスポートし；その後、別マシンのテンプレートライブラリに bundle-import して、
インポート後の template_id と状態を列挙してください。
```

**アシスタントが必ず守るべきハードルール**
- セマンティックな判読はパッケージ内の `skills/template-distill/SKILL.md` に従って実行します；決定論的なステップで「即興」をしてはいけません。
- `measured / id / image_sha256 / source_image / schema_version` は保護フィールドで、patch に含めると拒否されます；キャンバスを変えるには `measure --force` を再実行するか、`canvas.height_in` を実測と 3% の許容差で合わせます。
- `ready` は検証と人間による review の両方を通過する必要があります；review なしの `approve` は拒否されます。`--force` はあなたが明示的に要求した場合のみで、レビュー記録に書き込まれます。
- プレビュー画像をあなたに見せ、サンプルと並べて照合した後でなければ承認できません。
- 期刊（学術誌）/教材のサンプル図は既定でローカルライブラリに入れるだけにし、公開 bundle をエクスポートしないでください（著作権）。

**よくある質問**
- **プレビューが失敗/画像が出ない**：本バージョン（v2.0.1）は v2.0.0 の `run-distill.ps1 --out` パラメータバインド問題を修正済みです；それでも失敗する場合は、先に `install\01-check.cmd` のセルフチェックを実行してください。
- **図幅を測定できない**：サンプル図が暗すぎる/ぼやけすぎている、または明るい帯がはっきりしない場合——鮮明な全体図のスクリーンショットに替えてください。
- **検証が 3% の許容差エラーを報告する**：`canvas.height_in` が実測と合っていません；measured を手で編集せず、canvas を直すか再測定してください。
- **テンプレート状態 `ready` は変更できない**：spec を複製するか、新しい id で再インポートしてください。納品済みテンプレートを壊さないように。

### 🔍 依存関係の監査（なぜ「全部同梱」と言えるのか）

- 🧩 add-in：自己完結型の C# アセンブリで、Pro 3.7 のサポート環境に含まれる .NET Desktop Runtime 10 x64 上で動作——本パッケージに別途 .NET のインストールは不要です。

## 🧪 オプションコンポーネントの使い方

**🐍 RunCode ツールボックス**（arcpy を高頻度で使う場面）
- パス：`%LOCALAPPDATA%\ArcGIS Pro MCP\runcode\RunCode.pyt`
- AI に `run_python_toolbox_tool` を呼ばせるとき、このパスを渡すだけです；または Pro の「挿入 → ツールボックス → ツールボックスの追加」で選択します。
- 各 Pro セッションの初回実行で「サードパーティ コード ライブラリ」の信頼ダイアログが出ます：先に `03-dialog-guard.cmd` を実行しておけば、ガードが自動で「はい」をクリックします ✨。

**🔌 Python ブリッジ**（arcpy セッションを呼び出し間で保持したいとき）
1. ArcGIS Pro のメニュー **解析 → Python** から Python ウィンドウを開きます；
2. 貼り付けて実行します（パスは既定のインストール位置に合わせて記入済み）：
   ```python
   import sys; sys.path.insert(0, r"C:\Users\<your-username>\AppData\Local\ArcGIS Pro MCP\plugin")
   import mcp_bridge; print(mcp_bridge.start_server(port=6511))
   ```
3. `CURRENT`（現在のプロジェクト）が必要なときは 1 行追加します（メインスレッドで実行する必要があります）：
   ```python
   print(mcp_bridge.start_pump())
   ```

**🛡️ ダイアログガード**（RunCode 実行前や ENVI→Pro 連携フローの前に起動を推奨）
```
03-dialog-guard.cmd                 # 600 秒ガード
03-dialog-guard.cmd -DurationSeconds 120
03-dialog-guard.cmd -NotifyTest     # リマインダー窓のみテスト（30 秒）
03-dialog-guard.cmd -AlertOnly      # 警告のみ、自動クリックなし
```
安全境界：「第三方 / 代码库 / third-party / code library」の文脈を持つ信頼ダイアログのみ処理します；**上書き、削除など他の確認ダイアログには決して触れません** 🙅。ログは `%LOCALAPPDATA%\ArcGIS Pro MCP\guard\watch_pro_dialog.log`。

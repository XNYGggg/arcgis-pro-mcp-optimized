# 使用指南

## 1. 三种能力层

add-in 把可用能力分成三层，AI 助手会自动选择最快的一层：

1. **113 个原生工具**（进程内执行，约 9 ms）：图层、属性、选择、符号、标注、布局、栅格、编辑等日常操作。
2. **全部地理处理工具**：通过 `run_geoprocessing_tool` 按名称调用 Pro 的约 2000 个 GP 工具，参数按名字写，不用记顺序。
3. **任意 arcpy**：可选。通过 RunCode 工具箱（本包已带）或 Python 桥（本包已带）执行任意 Python。

## 2. 首次使用流程

1. 运行 `install\00-install.cmd`（关闭 Pro 时执行）。
2. 打开 ArcGIS Pro → 如提示加载项不受信任 → 选“是”。
3. 顶部 **MCP 选项卡** 确认：`running`，HTTP `127.0.0.1:6520`。
4. 接入客户端（见 `clients\`），运行 `install\01-check.cmd` 自检。
5. 打开一个有数据的工程，直接对话，例如：
   - “按面积给所有区县做分级色彩，用从浅红到深绿”
   - “选出人口大于 50 万的县，另存为新的要素类”
   - “把当前地图视图导出成 PNG 并显示出来”
   - “用布局模板 A 出一张 A3 竖版 PDF”

## 3. RunCode 工具箱（高频 arcpy）

- 路径：`%LOCALAPPDATA%\ArcGIS Pro MCP\runcode\RunCode.pyt`
- 用途：让 AI 一次性执行一段 arcpy 代码（批量处理、复杂表达式、循环），比逐个工具调用快。
- 两种用法：
  1. AI 调用 `run_python_toolbox_tool`，工具箱路径传上面那个 `.pyt`；
  2. 在 Pro 里“插入 → 工具箱 → 添加工具箱”手动添加。
- 每个 Pro 会话首次运行会弹“是否允许第三方代码库 Python 命令执行”：
  - 推荐：运行前先双击 `install\03-dialog-guard.cmd`，守护自动点“是”；
  - 或手动点一次，本会话内不再弹。

## 4. Python 桥（可选，进阶）

只在两种情况下需要：需要跨多次调用保持 Python 会话变量；需要 `CURRENT`（打开的工程对象）。

1. ArcGIS Pro → **分析 → Python** 打开 Python 窗口；
2. 粘贴：
   ```python
   import sys; sys.path.insert(0, r"C:\Users\<你的用户名>\AppData\Local\ArcGIS Pro MCP\plugin")
   import mcp_bridge; print(mcp_bridge.start_server(port=6511))
   ```
3. 需要 `CURRENT` 时，在同一窗口再执行（必须主线程）：
   ```python
   print(mcp_bridge.start_pump())
   ```
4. 每个 Pro 进程只需粘贴一次；Pro 关闭后桥随之消失。

## 5. 弹窗守护（推荐在 RunCode / ENVI 联合流程前启动）

```
install\03-dialog-guard.cmd                  # 启动 600 秒守护
install\03-dialog-guard.cmd -DurationSeconds 120
install\03-dialog-guard.cmd -NotifyTest      # 测试提醒窗（30 秒自动关闭）
install\03-dialog-guard.cmd -AlertOnly       # 只提醒、不自动点击
```

- 自动点击成功：无感。
- 自动点击失败：右上角出现置顶提醒窗（至少 30 秒，每 10 秒响铃），并把 Pro 提到最前，等你手动点。
- 安全边界：只处理“第三方代码库”信任框，覆盖/删除等其他确认框一律不碰。
- 日志：`%LOCALAPPDATA%\ArcGIS Pro MCP\guard\watch_pro_dialog.log`

## 6. 常见工作流建议

- **大批量任务**：让 AI 优先用一个 arcpy 脚本（RunCode）整体完成，而不是几十次工具调用。
- **大工程/大栅格**：按范围或 OID 分块处理，让 AI 写幂等脚本并留检查点。
- **出图收尾**：先让 AI 自检（图层、比例尺、图例、导出分辨率），再人工验收。
- **ENVI 联合流程**：ENVI 成果导入 Pro 前后属于 Pro 操作，同样建议先起弹窗守护。

## 7. 升级与卸载

- 升级：解压新客户版，直接运行新版 `00-install.cmd`（会备份旧 add-in 并覆盖运行时）。
- 卸载：`install\99-uninstall.cmd`（默认同时清理 Claude Desktop / Claude Code 的 arcgis 条目；加 `-KeepClientConfig` 可保留）。

# 工作规则（给使用 AI 助手的人）

本文件是使用建议，不是硬性限制；核心目标是让 AI 驱动 Pro 的过程**快、稳、可验收**。

## 1. 工具选择顺序

1. 原生工具（最快，毫秒级）→ 2. `run_geoprocessing_tool`（任意 GP）→ 3. RunCode 工具箱（一段 arcpy 批量完成）→ 4. Python 桥（需要持久会话或 `CURRENT` 时）。

## 2. 什么时候用批量脚本

约 5 条以下的重复操作直接逐个调用即可；重复度高、数据量大时，让 AI 写一个幂等 arcpy 脚本一次执行，比几十次工具调用更快、更稳。

## 3. 大任务分块

内存/时间受限时，按 OID 区间、分幅范围或栅格瓦片分块处理，写检查点，全部完成后合并并统一校验计数与关键统计。不可分块的操作（汇流累积、全局拓扑等）整体执行。

## 4. 弹窗守护的适用场合

- 首次运行 RunCode 工具箱前；
- ENVI 成果导入 ArcGIS Pro 及其后的 Python 工具环节；
- 任何预期会弹“第三方代码库执行”确认框的批量流程。
- 守护只点信任框；覆盖、删除等确认框必须人工决策。

## 5. 出图验收

导出前让 AI 自检：图层齐全、符号与图例一致、比例尺/指北针正确、文字不压盖、导出分辨率达标；导出后人工确认再交付。

## 6. 数据安全

- MCP 服务仅监听本机回环地址，不对外网开放。
- 让 AI 执行删除、覆盖类操作前，要求它先说明影响范围，必要时先备份工程。

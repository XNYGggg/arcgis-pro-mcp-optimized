# 排障手册

先跑 `install\01-check.cmd`，它会把问题定位到具体环节。日志位置：

| 日志 | 路径 |
|---|---|
| add-in 日志 | `%LOCALAPPDATA%\ArcGIS-MCP\addin.log` |
| 弹窗守护日志 | `%LOCALAPPDATA%\ArcGIS Pro MCP\guard\watch_pro_dialog.log` |
| 安装标记 | `%LOCALAPPDATA%\ArcGIS Pro MCP\installed.json` |

## 1. Pro 里看不到 MCP 选项卡

- 确认 add-in 文件存在：`%USERPROFILE%\Documents\ArcGIS\AddIns\ArcGISPro\ArcGISProMCP.esriAddinX`（`01-check.cmd` 会检查）。
- **重启 ArcGIS Pro**：add-in 只在启动时加载。
- 首次加载会提示“不受信任的加载项”，必须点“是”；若当时点了否，Pro 会记住拒绝——在 Pro 的“加载项管理器”里删除该条目后重启，或重新运行安装脚本并再次确认。
- 若公司策略强制“仅允许已签名加载项”，未签名 add-in 会被拒载；需要在 Pro 设置/管理员策略中允许未签名加载项。

## 2. 端口 6520 不通 / MCP 选项卡显示 stopped

- 必须先打开 ArcGIS Pro，桥接运行在 Pro 进程内。
- 看 MCP 选项卡上的三个端口状态：`6520`（HTTP，AI 客户端用）、`6510`（旧 TCP）、`6511`（可选 Python 桥）。
- 安全软件/防火墙拦截本机回环连接：把 PowerShell 与 ArcGISPro.exe 加入白名单。
- 端口被别的程序占用：`netstat -ano | findstr 6520`，结束占用进程或重启 Pro。

## 3. 首次 RunCode 一直卡住

这是 Pro 在等“第三方代码库 Python 命令执行”的确认。先运行 `install\03-dialog-guard.cmd` 再重试；或直接切到 Pro 手动点“是”。

## 4. Claude Desktop 配置不生效 / 被还原

Claude Desktop 运行期间会用内存配置覆盖磁盘文件。**完全退出应用**后再运行 `02-configure-claude.cmd`，然后重新打开。

## 5. Claude Code 显示连接失败

- 确认 Pro 已开、6520 在监听；
- `claude mcp list` 看是否有 `arcgis`；没有则重新执行：
  `claude mcp add --transport http arcgis http://127.0.0.1:6520/mcp`
- 若之前用 stdio 方式注册过同名服务，先 `claude mcp remove arcgis`。

## 6. Codex 连不上

确认 `~/.codex/config.toml` 中是：

```toml
[mcp_servers.arcgis]
url = "http://127.0.0.1:6520/mcp"
```

并重启 Codex。

## 7. Python 桥报错

- `sys.path.insert` 的路径要指向 `%LOCALAPPDATA%\ArcGIS Pro MCP\plugin`（本机实际路径）。
- 端口 6511 被占用时换一个端口。
- `start_pump` 必须在主线程（Pro 的 Python 窗口）执行，否则 `CURRENT` 不可用。

## 8. 中文乱码

- 所有 .ps1 脚本以带 BOM 的 UTF-8 保存，PowerShell 5.1 可正确显示中文。
- 若在旧终端看到乱码，先执行 `chcp 65001`。

## 9. 收集诊断信息给支持方

```powershell
install\01-check.cmd > diag.txt 2>&1
```

把 `diag.txt`、`addin.log`、`installed.json` 一起提供即可定位大部分问题。

## 10. Pro 重启/升级后仍显示旧工具（如缺 template_delete）

- Pro 重启或升级 add-in（例如 1.1.12 → 1.1.13，工具数 125 → 126）后，**AI 客户端会话里的工具表是连接时快照**，不会自动刷新。
- 处理：**重开客户端会话**——Claude Code 退出该会话重开（或先 `claude mcp remove arcgis` 再重新添加）；Claude Desktop 完全退出应用再打开；Codex 重启进程。重开后 `tools/list` 应出现新工具（1.1.13 为 `template_delete`，共 126 个）。
- 不重启客户端时，可直接用 HTTP 端点核对服务端工具表：`http://127.0.0.1:6520/mcp` 的 `tools/list`（例如用 `curl` 发 MCP `initialize` + `tools/list`），服务端若已包含新工具即说明升级成功，只差客户端重连。
